## ✨ Why Eclipse Client?

**Eclipse Client** is a cutting-edge, free-to-use Minecraft launcher designed specifically for competitive PvP players seeking maximum smoothness, zero micro-stutters, and insane FPS boosts. Equipped with an automated optimization mod injector and a customizable in-game HUD engine, Eclipse transforms your Minecraft experience into something out of this world.

---

## ⚡ Key Features

* **🚀 100,000 FPS Optimization Engine:**
  * Automatically injects performance mods (Sodium, Lithium, FerriteCore for Fabric / OptiFine, Patcher for Forge).
  * Pre-configured JVM arguments to prevent frame drops and memory leaks.
* **🎮 Customizable In-Game HUD:**
  * **FPS & Ping Display:** Real-time performance monitors.
  * **CPS Counter:** Left & Right click speed visualizer.
  * **Keystrokes HUD:** On-screen WASD and mouse overlays.
  * **ToggleSprint & Armor Status:** Essential PvP HUD elements with full color and position customizability.
* **🔓 Offline & Cracked Account Manager:**
  * Play instantly without Microsoft/Mojang OAuth hurdles.
  * Create custom offline profiles, generate offline UUIDs, and manage local skins easily.
* **🌌 Space-Themed Interface (Glassmorphic UI & Starfield):**
  * Modern obsidian dark layout featuring an interactive space particle canvas, glowing neon highlights, and sleek panel glassmorphism.
  * Built-in RAM allocation manager and instant version switcher (1.8.9, 1.16.5, 1.20.4+).
* **📰 Dynamic News Stream:**
  * Live updates, patch notes, and event banners fetched directly from the official web CMS.
